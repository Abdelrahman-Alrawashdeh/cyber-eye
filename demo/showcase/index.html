Platform tour

Inside the CYBER EYE monitoring stack

In production, these tools run on the protected internal network and are not exposed to the internet. This tour shows them exactly as they appear in the running environment.

  • Grafana
  • Elasticsearch
  • Logstash
  • Kibana
  • Alertmanager
  • MySQL
  • Docker

01 · Security operations

Grafana dashboards

Real-time attack status, geographic attack sources, most-targeted hosts and services, port and protocol distribution, and alert timelines by severity.

02 · Log analytics

Kibana

Every event is shipped through Logstash into Elasticsearch, where analysts can search, filter and investigate raw records.

03 · Alerting

Alertmanager & email notifications

Grafana alert rules route through Alertmanager, which delivers branded email notifications with severity, timing and an executive summary.

04 · Architecture

Lab network topology

The virtual lab network monitored by CYBER EYE: segmented hosts, switching and routing layers, and the monitored perimeter. Platform data is stored in MySQL.
